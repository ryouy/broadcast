# Broadcast

Broadcastは、管理画面でお知らせを作り、XとInstagramへの投稿を管理する個人用アプリです。

**管理画面:** https://broadcast.ryouy.workers.dev/

## 使い方
1. 許可されたGoogleアカウントでログインする。
2. 「投稿を作成」で本文と投稿先（X / Instagram）を選ぶ。画像は投稿画面から選択できます（Cloudflare R2の有効化・接続後）。
3. 「確認待ちに保存」する。**保存だけではSNSへ投稿されません。**
4. 「投稿一覧」で内容を確認し、問題なければ「投稿を承認」する。
5. 承認した投稿はCloudflare Cronから送信される（現状は最大約15分の待ち時間）。

## 機能
- Google OAuthによる管理者認証、許可メールアドレス制限
- 投稿文の作成、投稿先の選択、確認待ち保存、承認・見送り
- SNS別の送信状態・投稿履歴管理
- JPEG・PNG・WebP画像の選択・プレビュー・R2アップロード（8MB以内、R2有効化後）
- SNSの認証情報が未設定なら投稿承認を拒否
- 送信結果が曖昧な場合は自動再送せず、二重投稿を防止


## 画像アップロードの有効化

画像アップロード用のWorker APIと投稿画面は実装済みですが、**CloudflareアカウントでR2をまだ有効化できていないため、本番環境の画像選択は無効**です。R2を有効化し、R2バケット `broadcast-media` を作成してください。Worker `broadcast` に、R2バケットへのバインディングを変数名 `MEDIA` で追加し、再デプロイすると使用可能になります。

アプリは `POST /api/media`（Googleログイン・同一オリジン必須）でファイルのサイズ・Content-Type・ファイル先頭の形式を確認し、UUIDベースのファイル名でR2に保存します。画像は `/media/<UUID>.<拡張子>` から取得でき、SNSによる画像取得のために公開URLとなります。機密画像や非公開画像はアップロードしないでください。投稿文は、画像アップロード後も承認するまではSNSに送信されません。

現在のX投稿APIは画像添付未対応です。InstagramはR2画像URLを指定した投稿に対応するコードがありますが、SNS連携自体の実投稿検証は別途必要です。
